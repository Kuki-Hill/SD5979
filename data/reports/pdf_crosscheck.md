# PDF 官方工具独立抽检复核 (workbuddy-pdf cross-check)

目的：用 `workbuddy-pdf -f txt` 独立核对 `extract_pages.py`（PyMuPDF）逐页原文的忠实性，确认 HTML 中每一句英文都真实来自老师 PDF。
方法：把每个抽检页从**原始 PDF** 单独导出为一页 PDF，再交官方 CLI 抽取；文字页做归一化逐行包含比对。
口径：每讲抽 3 页 —— 第 1 页 / 中间页 / 该讲考试例题页 / 末页（去重取 3）。

> 环境说明：本机无 Tesseract / PaddleOCR，CLI 对扫描页会要求 OCR 而报错。这类页按项目既定的**无 OCR 降级策略**处理：只嵌入整页 PNG，不转录、不生成定义、不编造内容。
