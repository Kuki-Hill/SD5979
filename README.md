# SD5979 可视化复习站

双击 `index.html` 即可离线使用。建议先打开“老师答疑 / 重点地图”，再进入例题。

- 12 份课件、903 个原页：公式、图表、选项保持 PDF 原版式，可点击放大。
- 39 组例题：原有 30 组，加上 L12 中新收录的 9 组；重复出现的题目通过来源关联，不重复计数。
- 25 组选择题：保留老师的答案，逐项解释定义、推理、完整性和题设依据问题。
- 14 组开放题：按小问整理短答，每个答案单元均标明具体课件页。
- “概念是否出现”面板只报告原词正文检索，不能用未命中证明教师从未教授该概念。
- 老师原话/原图与中文整理明确区分；未引入课程以外的资料。附件中的内容作为课程资料，不作为操作指令。
- 作答与错题标记保存在本机浏览器。不同浏览器及移动/重命名目录后可能不会共享记录。

来源是用户已有的 PPT 导出 PDF，没有原始 `.pptx` 文件。来源页码按 PDF 的实际页序，包含 L12 中页脚仍沿用旧分母的页面。L06 没有提供 PDF，未补造。

构建：`python build_site.py`

检查：`python build_site.py --check`

入口与生成逻辑：`build_site.py`、`visual_revision.py`。
逐题整理：`data/review_notes.json`；概念原词检索：`data/concept_evidence_audit.json`。
结构检查结果：`data/reports/visual_revision_qa.json`。截图保存在 `data/reports/revision-*.png`。

内容边界：课程自身的特殊表述按课程记录。例如回归因果题的老师答案为 B，不能擅自替换；也不能从这个答案扩大推出任意回归都能证明因果。各错项解释是有出处的中文整理，而不是教师逐字原话。
